## How to Play

1. **Start**: Enter a 10-letter starting word (or use the Random button).
2. **Form Words**: Make new words using only the letters from your current word (letter repetition is allowed).
3. **Score Points**: Each valid word formed adds its length to your score.
4. **Bonus Letters**: Every 15 points, you unlock a bonus letter which you can claim to expand your available letters for the next turn.
5. **Game Over**: When no more valid English words can be formed from the current available letters, the game ends.
